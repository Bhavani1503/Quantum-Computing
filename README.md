# Molecular Ground-State Energy Estimator (VQE for H2)

## Run
    pip install -r requirements.txt
    streamlit run app.py

## Files
- vqe.py            : Hamiltonian, circuit, energy, optimizer (all the VQE logic)
- app.py            : Streamlit website (Input -> Processing -> Output)
- requirements.txt  : Python packages
- .streamlit/       : light theme settings
